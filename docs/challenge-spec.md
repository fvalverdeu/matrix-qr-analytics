# Matrix QR Analytics - Challenge Specification

## Objective

Build a solution composed of two independent REST APIs that communicate through HTTP.

The solution must receive a rectangular matrix, perform QR decomposition, calculate statistics from the resulting matrices, and return a consolidated response.

---

## Technical Constraints

The following constraints are mandatory:

- Go (Golang)
- Fiber framework
- Node.js
- Express.js framework
- Docker
- HTTP communication between services
- JSON payloads
- No persistence layer

---

## Services

### QR Service (Go + Fiber)

Responsibilities:

- Receive a rectangular matrix.
- Validate input.
- Perform QR decomposition.
- Send resulting matrices to the Statistics Service.
- Return a consolidated response.

---

### Statistics Service (Node.js + Express)

Responsibilities:

- Receive matrices generated by the QR Service.
- Calculate:
  - Maximum value
  - Minimum value
  - Average value
  - Total sum
  - Diagonal matrix verification

---

## Expected Flow

Client

→ QR Service

→ Statistics Service

→ QR Service

→ Client

---

## Optional Features

- JWT authentication
- Frontend application
- Unit tests
- Integration tests
- Cloud deployment

---

## Success Criteria

The solution is considered complete when:

1. Both services run independently.
2. Services communicate through HTTP.
3. QR decomposition is correctly calculated.
4. Statistics are correctly calculated.
5. The solution runs using Docker Compose.
6. Documentation is provided.
